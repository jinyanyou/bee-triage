# 판별 정확도 평가

## 왜 필요한가

- 공모전 유의사항: **"주관기관은 필요 시 사용한 AI 도구 및 활용 방식에 대한 설명을 요구할 수 있음"**
- 본선 심사 완성도·실현성 항목에서 "정확도가 어떻게 되나요"에 숫자로 답하기 위해
- 현재 신뢰도 임계값 `0.70`은 근거 없이 정한 값이다. 이 스크립트로 근거를 만든다.

## 준비

**표본 20장과 `labels.csv`가 이미 준비되어 있습니다.** `prototype/.env`에
`ANTHROPIC_API_KEY`만 넣으면 바로 실행됩니다.

표본을 더 넣으려면:

1. `images/` 에 사진을 추가한다
2. `labels.csv` 에 정답 행을 추가한다 (`labels.example.csv` 형식 참고)

```csv
file,actual_grade,actual_species,note
velutina_eaves_01.jpg,고위험,등검은말벌,처마 밑 폐쇄형 종 모양 집
```

`actual_grade`는 `고위험` / `중위험` / `저위험` / `판별불가` 중 하나.

3. `prototype/.env` 에 `ANTHROPIC_API_KEY` 설정 (LIVE 모드 필요)

## 실행

```
cd prototype
.venv\Scripts\python.exe -m eval.run_eval
```

옵션: `--limit 10` (앞 10장만), `--out eval/report.md`

## 결과물

- `eval/report.md` — 심사 답변에 그대로 쓸 수 있는 마크다운 리포트
- `eval/results.json` — 원시 결과

## 무엇을 보는가

단순 정확도보다 **안전 지표**가 중요하다.

| 지표 | 의미 | 목표 |
|---|---|---|
| **위험 과소평가** | 실제보다 낮은 등급으로 판정 | **0건** |
| 불필요 119 이관 | 실제 저위험인데 119로 보냄 | 낮을수록 좋음 |
| 등급 일치율 | 정답과 판정이 같은 비율 | 참고 지표 |

위험 과소평가가 1건이라도 나오면 임계값을 올리거나 few-shot 참조 사진
(`reference/`)을 보강해야 한다. 리포트의 **신뢰도 임계값 스윕** 표가
"과소평가 0을 만족하는 최소 임계값"을 알려준다.

## 표본 구성 권장

| 등급 | 장수 |
|---|---|
| 고위험 (장수말벌·등검은말벌) | 8~10 |
| 중위험 (쌍살벌류) | 6~8 |
| 저위험 (꿀벌·분봉) | 6~8 |
| 판별불가 (흐림·역광·원거리) | 3~5 |

**중요:** `reference/`에 넣은 few-shot 사진은 평가 표본에서 제외해야 한다.
같은 사진으로 학습하고 평가하면 의미가 없다.
