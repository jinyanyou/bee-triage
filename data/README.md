## 3. 처리 순서
1. `scripts/02_preprocess.py` — 소독업·양봉농가 정제 (시도/시군구 추출, 영업중 필터, EPSG:5174→WGS84, 전화번호 정규화)
2. `scripts/03_enrich_fire_centers.py` — 119센터 좌표 확정, 매칭 DB 좌표 결측 11건 보완, 센터별 근접성 계산
   - 센터 좌표 우선순위: 소방청 좌표(주소 일치 120) → 소방청 좌표(명칭·도로명 일치 6) → OSM 지오코딩(29)
   - 소방청 좌표 파일은 2024년 기준이라 이후 이전한 센터(신천·하양·감포·봉화·영양·청송 등)는 지오코딩으로 대체
3. 통계(stats_*)는 소방청 통계연보 PDF 표를 직접 옮김
   - 2016~2025: 「2026 소방청 통계연보」 4-2-1-2 연도별 119생활안전출동 현황 (p.154)
   - 2025 본부별: 같은 연보 4-2-1-1 (p.153) / 2024 본부별: 「2025 소방청 통계연보」 4-2-1-1 (p.149) / 2023 본부별: 「2024 소방청 통계연보」 4-2-1-1 (part04 p.147)

## 4. 핵심 수치
- 벌집제거 출동(전국): 2024년 304,821건(생활안전의 45.5%) → **2025년 235,804건(40.3%, 전년 대비 -22.6%)**
- 대구: 9,784건 → 8,212건(-16.1%) / 경북: 30,068건 → 24,583건(-18.2%, 생활안전의 53.7%)
- 대구 안전센터 51곳 중 50곳, 경북 104곳 중 83곳이 반경 5km 내 영업중 소독업체 보유
- 센터→가장 가까운 연락가능 업체 거리 중앙값: 대구 0.57km / 경북 2.03km

## 5. 한계·주의
- **기획서 수치 갱신 필요**: 초안의 30만 4,821건·30.8% 증가는 2024년 값. 최신(2025)은 감소 추세이므로 "최근 10년 중 2024년 최고치, 2025년에도 생활안전 출동 1위(40.3%)"처럼 서술 권장
- 기획서 초안의 경북 2024년 29,688건은 통계연보 값(30,068건)과 다름 → 출처 확인 필요
- 2016~2021년은 '벌퇴치·벌집제거' 분류, 2022년부터 분류체계 변경(연보 주석) → 시계열 비교 시 각주 표기
- 월별 집중도는 통계연보에 없음. 필요 시 정보공개청구(건별 데이터) 결과로 산출
- 매칭 DB 전화번호 결측 586건(57.5%) → 연락가능 433곳
- OSM 지오코딩 좌표 중 '도로중심'·'행정구역중심'은 수백 m~수 km 오차 가능 (센터 19곳, 업체 10곳) → 카카오 지오코딩 키 확보 시 재보정
- 소독업 인허가 ≠ 벌집 제거 서비스 제공 여부
- 양봉농가 데이터는 법인 39곳 신청 이력뿐(연락처 없음) → 매칭 불가
- 양봉협회 지회장·사무국장 개인 이름·주소(자택 추정)는 개인정보라 저장하지 않음. 협회 안내대로 지회 연락은 본회 사무국(02-3486-0882~5) 경유
