# few-shot 참조 사진

`app/vision.py`가 판정할 때, 판정 대상 사진 **앞에** 여기 등록된 참조 사진들을
in-context exemplar로 붙여 보냅니다. 정답이 확인된 사진을 몇 장 넣어두면
판별 정확도가 눈에 띄게 올라갑니다.

현재 **9장이 등록되어 있습니다** (고위험 3 / 중위험 3 / 저위험 2 / 판별불가 1).
출처·라이선스는 `../CREDITS.md`를 보세요.

참조 사진이 하나도 없어도 동작합니다. 그 경우 시스템 프롬프트의 텍스트 예시
3건만으로 판정합니다.

## 넣는 방법

1. 이미지 파일을 이 폴더에 복사합니다. (jpg / png / webp / gif)
2. `manifest.json`에 항목을 추가합니다.

```json
[
  {
    "file": "velutina_01.jpg",
    "risk_grade": "고위험",
    "species": "등검은말벌",
    "note": "건물 외벽에 매달린 폐쇄형 종 모양 집, 지름 25cm급"
  }
]
```

| 필드 | 설명 |
|---|---|
| `file` | 이 폴더 기준 파일명 (하위 폴더 가능) |
| `risk_grade` | `고위험` / `중위험` / `저위험` / `판별불가` |
| `species` | 종 이름 (예: 장수말벌, 양봉꿀벌(분봉)) |
| `note` | 어떤 시각적 특징이 근거인지 한 줄 |

서버를 재시작하면 반영됩니다. (`manifest.json`은 캐시됩니다)

## 권장 구성

등급별로 2~3장씩, 총 8~12장이 적당합니다. 너무 많으면 토큰 비용과 지연이 늘어납니다.

| 등급 | 넣으면 좋은 것 |
|---|---|
| 고위험 | 등검은말벌 폐쇄형 집, 장수말벌 개체 근접, 땅속/처마 안쪽 은폐형 |
| 중위험 | 쌍살벌 개방형 집(육각방 노출), 소형 초기 벌집 |
| 저위험 | 꿀벌 분봉 덩어리, 밀랍 판(comb) 형태 벌집, 꿀벌 개체 근접 |
| 판별불가 | 역광/흔들림/원거리로 형태가 안 읽히는 사진 |

**중요:** 시민이 폰으로 찍은 것과 비슷한 화각·화질이어야 의미가 있습니다.
도감식 매크로 접사 사진은 실제 신고 사진과 괴리가 커서 오히려 역효과입니다.

## 사진 출처

- [iNaturalist](https://www.inaturalist.org/) — `Vespa velutina`, `Vespa mandarinia`,
  `Apis mellifera`로 검색. 라이선스가 CC BY / CC BY-NC / CC0인 관측 사진만 사용하세요.
- [GBIF](https://www.gbif.org/) — 종별 미디어 검색 가능
- 팀원이 직접 촬영한 사진

공모전 유의사항상 **저작권·초상권 책임은 참가자에게** 있습니다. 라이선스와 저작자
표시를 `manifest.json`의 `note`나 별도 `CREDITS.md`에 남겨두세요.
