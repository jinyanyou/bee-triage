# 업체 전화 조사 가이드

> `market_sizing.py`의 **가정값을 실측으로 바꾸기 위한** 통화 스크립트입니다.
> 동시에 예선 심사 **협력성(15점)** — "민간기업·공공기관 등 팀 외부 주체와의 협력 여부"
> 의 근거가 됩니다. 한 번의 전화로 두 가지를 얻습니다.

## 무엇을 확정해야 하는가

| 확정할 값 | 현재 상태 | `market_sizing.py` 변수 |
|---|---|---|
| 건당 단가 | 5만 / 8만 / 12만원 **가정** | `PRICE_SCENARIOS_KRW` |
| 업체 1곳 일 처리량 | 2건 **가정** | `CASES_PER_COMPANY_PER_DAY` |
| 성수기 집중도 | 연간의 75% **가정** | `PEAK_SHARE_OF_YEAR` |
| 유상 선택률 | 30 / 50 / 70% **가정** | `PAID_CHOICE_SCENARIOS` |
| 저위험 구간 비중 | 40% **가정** | `LOW_RISK_SHARE` (소방서 문의) |
| (보너스) 벌집 제거 실제 수행 여부 | 미확인 | 매칭 DB 필터 근거 |

**3~5곳이면 충분합니다.** 대구·경북에서 연락 가능 업체가 많은 시군구
(대구 달서구 37곳, 동구 34곳, 북구 34곳 / 경북 구미 47곳, 포항 44곳)에서 고르세요.
번호는 `data/matching_db_disinfection_daegu_gb.csv`의 `전화번호` 열에 있습니다.

## 통화 스크립트

### 여는 말 (신분을 밝히고 시작합니다)

> "안녕하세요. 저희는 벌집 제거 신고를 119 대신 민간 업체로 연결하는 서비스를
> 공모전에 준비 중인 대학생 팀입니다. 사업 계획을 세우는 데 현장 얘기를 듣고 싶어서
> 연락드렸습니다. 5분 정도만 여쭤봐도 될까요?"

**주의:** 실제 발주나 계약처럼 오해하게 만들지 마세요. 조사 목적임을 분명히 밝힙니다.

### 질문 (순서대로, 6개)

**Q1. 벌집 제거 작업을 실제로 하시나요?**
- 예 / 아니오 / 가끔
- → *소독업 인허가가 곧 벌집 제거 수행을 뜻하지 않습니다. 아니라면 여기서 정중히 종료.*

**Q2. 벌집 제거는 보통 얼마 정도 받으시나요?**
- 기본 단가 ______ 원
- 높이·위치에 따라 달라지나요? (사다리차 필요 시 ______ 원)
- 말벌과 꿀벌이 가격이 다른가요?
- → `PRICE_SCENARIOS_KRW`

**Q3. 여름 성수기에 벌집 관련 문의가 하루 몇 건쯤 오나요?**
- 문의 ______ 건 / 실제 작업 ______ 건
- → `CASES_PER_COMPANY_PER_DAY`

**Q4. 벌집 문의가 몰리는 시기는 언제인가요?**
- 몇 월부터 몇 월까지 ______
- 1년 전체 중 그 기간 비중이 어느 정도라고 보시나요? ______
- → `PEAK_SHARE_OF_YEAR`

**Q5. 막상 가보니 "굳이 안 부르셔도 됐을 텐데" 싶은 건이 어느 정도 되나요?**
- 전체의 ______ % 정도
- 그런 고객은 왜 부른다고 보시나요? (불안해서 / 벌을 못 알아봐서 / 기타 ______)
- → `PAID_CHOICE_SCENARIOS` — 저위험인데도 **불안해서 돈 내고 맡기는 비율**의 실측치입니다.
  업체는 이미 그런 고객을 받고 있으므로 답할 수 있는 유일한 대상입니다.

**Q6. 위치와 사진이 정리된 의뢰가 앱으로 들어온다면 받아보실 의향이 있으신가요?**
- 있다 / 없다 / 조건부(______)
- 수수료를 낸다면 몇 %까지 괜찮으신가요? ______
- → `MATCHING_FEE_RATE` 검증 + **이용자 확보 전략의 직접 근거**

## 통화 후 할 일

1. `interviews.csv`의 단가 중앙값으로 `PRICE_SCENARIOS_KRW`를 갱신
   (여전히 3개 시나리오로 두되, 실측 중앙값을 가운데 값으로)
2. `CASES_PER_COMPANY_PER_DAY`, `PEAK_SHARE_OF_YEAR`, `PAID_CHOICE_SCENARIOS` 갱신
3. `.venv\Scripts\python.exe -m analysis.market_sizing` 재실행
4. `market_report.md`의 "가정" 표시가 "실측 n=5"로 바뀌도록 수정

실측으로 바뀌는 순간 **"가정에 기반한 추정"이 "현장 조사에 기반한 추정"이 됩니다.**
심사에서 이 차이가 큽니다.

## 같이 연락하면 좋은 곳

| 대상 | 연락처 | 물어볼 것 |
|---|---|---|
| 한국양봉협회 사무국 | 02-3486-0882~5 | 분봉 회수 의향, 지회 연계 방식, 회수 시 보상 관행 |
| 지역 119안전센터 | `data/fire_centers_daegu_gb_with_proximity.csv` | 벌집 출동 중 비긴급 체감 비율(`DIVERSION_SCENARIOS`), **"현장에서 그냥 두셔도 된다고 안내하고 오는 비율"**(`LOW_RISK_SHARE`), 월별 집중도 |
| 지자체 재난안전과 | — | 민간 위탁 사례 유무, 예산 규모 |

소방서 문의는 **`DIVERSION_SCENARIOS`(비긴급 우회 비율)**와 **`LOW_RISK_SHARE`
(저위험 구간 비중)**를 좁히는 유일한 현실적 경로입니다. 정식 통계가 없으니 현장
체감이라도 확보하면 근거가 됩니다.

> **왜 이 두 값이 중요한가:** 저위험 구간은 신고자가 「자가 대응」과 「유상 처리」
> 중에서 직접 고릅니다. 자가 대응을 고르면 **매출은 0원이지만 소방력 절감 효과는
> 유상 처리와 같습니다.** 공익 가치와 사업 매출이 반대로 움직이는 구조라,
> 이 두 값이 수익 모델의 무게중심(매칭 수수료냐 지자체 위탁이냐)을 결정합니다.
