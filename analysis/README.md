# analysis — 시장성 분석

본선 심사 **시장성(30점)** — 「타겟 시장 구체화 및 이용자 확보 전략」 대응 자료.

| 파일 | 내용 |
|---|---|
| `market_sizing.py` | 계산 스크립트. 가정값이 전부 파일 상단에 모여 있다 |
| `market_report.md` | 실행 결과. 기획서에 표를 그대로 옮길 수 있다 |
| `sigungu_matrix.csv` | 시군구별 수급 매트릭스 (진입 순서 근거) |
| `interview_guide.md` | 업체 전화 조사 스크립트. 가정값을 실측으로 바꾸는 절차 |

## 실행

```
.venv\Scripts\python.exe -m analysis.market_sizing
```

## 설계 원칙

**단일 숫자를 제시하지 않는다.** 시장 규모를 하나의 값으로 내면
"그 숫자 근거가 뭐냐"는 질문 하나에 무너진다.

- 공공데이터에서 직접 나오는 값 = **확정값**
- 아직 실측하지 않은 값 = **가정값**, 민감도 분석으로 범위 제시

가정값 3개(건당 단가, 비긴급 우회 비율, 업체 처리량)는 `interview_guide.md`의
절차로 실측할 수 있다. 실측 후 스크립트 상단 숫자만 바꿔 다시 돌리면 리포트가
갱신된다.

## 다른 팀과 달라지는 지점

대부분의 팀은 수요(시장 크기)만 말한다. 우리는 **공급 측을 실제 업체 수로
점검**한다. 수요가 커도 받아줄 업체가 없으면 시장이 아니기 때문이다.

그리고 질문을 "공급이 충분한가"가 아니라 **"우회율 X%를 감당하려면 몇 곳이
참여해야 하는가"**로 뒤집었다. 이 값이 곧 사업 초기의 업체 모집 목표가 된다.
